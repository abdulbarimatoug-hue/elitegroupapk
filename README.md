# مجموعة النخبة للخدمات السياحية (LY-Elite Tourism Group)
## المنظومة المتكاملة: تطبيق العميل للهواتف (Android & iOS) + لوحة تحكم الإدارة (Flutter Web)

منظومة سياحية فاخرة تم بناؤها وتطويرها بأحدث المعايير البرمجية العالمية باستخدام **Flutter Clean Architecture** بنظام **Melos Monorepo** وقواعد بيانات **Firebase Firestore** ونظام المصادقة والإشعارات الفورية **FCM**.

---

## 🏗️ هيكلية المشروع (Melos Monorepo Architecture)

تم تقسيم المشروع إلى 4 حزم مستقلة ومنظمة لتحقيق أعلى درجات إعادة استخدام الكود وسهولة الصيانة:

```
├── melos.yaml                         # ملف إعدادات Melos لإدارة الحزم المشتركة
├── firestore.rules                    # قواعد أمان Firestore المحكمة مع عزل بيانات العملاء
├── packages/
│   ├── core_domain/                   # طبقة النطاق المشتركة (Pure Dart - No Frameworks)
│   │   ├── lib/
│   │   │   ├── entities/              # كيانات الأعمال: الباقات، الرحلات المخصصة، الطيران، التأشيرات، الإشعارات
│   │   │   ├── repositories/          # عقود وواجهات المستودعات (Interfaces)
│   │   │   └── failures/              # تصنيفات الأخطاء والاستثناءات الموحدة
│   ├── core_data/                     # طبقة البيانات المشتركة (Firebase & Remote Services)
│   │   ├── lib/
│   │   │   ├── models/                # نماذج تسلسل البيانات (JSON / Firestore Mappers)
│   │   │   ├── datasources/           # مصادر البيانات المباشرة (Firestore / Auth / FCM)
│   │   │   └── repositories/          # التطبيق الفعلي لعقود المستودعات
│   ├── customer_app/                  # تطبيق العميل للهواتف (Flutter Android & iOS)
│   │   ├── lib/
│   │   │   ├── core/                  # الثيم، الألوان الفاخرة، أدوات واتساب، مزودي Riverpod
│   │   │   └── features/
│   │   │       ├── onboarding/        # معالج الترحيب والتعريف
│   │   │       ├── auth/              # تسجيل الدخول وحساب جديد وGoogle Sign-In
│   │   │       ├── packages/          # الرئيسية، تصفح وفلترة الباقات وتفاصيلها
│   │   │       ├── custom_trip_builder/# مصمم الرحلة المخصصة (معالج الـ 6 خطوات)
│   │   │       ├── flight_booking/    # حجز تذاكر الطيران المستقل (ذهاب/عودة/مدن متعددة)
│   │   │       ├── visas/             # كتالوج بطاقات التأشيرات والتفاصيل
│   │   │       ├── bookings/          # سجل طلباتي وحجوزاتي ومتابعتها
│   │   │       ├── favorites/         # الباقات السياحية المفضلة
│   │   │       ├── notifications/     # مركز الإشعارات والتنبيهات
│   │   │       └── profile/           # الملف الشخصي وأرقام واتساب الشركة الثلاثة
│   └── admin_dashboard/               # لوحة تحكم الإدارة (Flutter Web Admin Control Panel)
│       ├── lib/
│       │   └── features/
│       │       ├── dashboard/         # لوحة المؤشرات والإحصائيات الحية (KPIs)
│       │       ├── packages/          # إدارة الباقات والبرامج اليومية والأسعار
│       │       ├── bookings/          # إدارة وتحديث حالات حجوزات الباقات
│       │       ├── custom_trips/      # إدارة طلبات الرحلات المخصصة
│       │       ├── flight_requests/   # إدارة طلبات تذاكر الطيران المستقلة
│       │       ├── visas/             # إدارة طلبات التأشيرات وبيانات الكتالوج
│       │       └── trip_builder_config/# إدارة محددات معالج الرحلة والحد الأدنى للميزانية
```

## 📱 ميزات تطبيق العميل (Customer App Features)

1. **لا دفع إلكتروني:** الامتثال الكامل لنموذج عمل الشركة؛ كل الحجوزات تُسجل بحالة `pending` وتُحوّل مباشرة إلى واتساب مع رقم مرجعي فريد.
2. **قنوات واتساب الثلاث الرسمية:**
   - خط المبيعات والحجوزات (الرئيسي): `+218 91 591 9921`
   - خط خدمة العملاء والاستفسارات: `+218 91 061 3800`
   - خط قسم الرحلات الخاصة والتأشيرات: `+218 91 061 3700`
3. **مصمم الرحلة المخصصة (معالج الـ 6 خطوات كامل):**
   - حفظ المسودة محلياً (`shared_preferences`) للاستئناف في أي وقت.
   - الخطوة 1: البيانات الأساسية، نوع الرحلة (عائلية، عمل، شبابية، شهر عسل)، قطاعات الأعمال، والحد الأدنى للميزانية ($1500).
   - الخطوة 2: تحديد متعدد للمدن والدول مع تنبيه تلقائي للتأشيرة المطلوبة ورابط مباشر لخدمة التأشيرات.
   - الخطوة 3: تحديد مدينة الانطلاق والدرجة وتوزيع الأيام مع عداد فحص التطابق اللحظي ووسائل التنقل الداخلي.
   - الخطوة 4: الاستقبال والتوديع بالمطار، نوع الإقامة، وتصنيف النجوم.
   - الخطوة 5: لغة المرشد السياحي ونوع الجولات (خاصة/جماعية) واهتمامات العميل.
   - الخطوة 6: بطاقة صعود الطائرة الاحتفالية (Boarding Pass)، تصدير PDF، و3 أزرار واتساب لأرقام الشركة.
4. **حجز تذاكر الطيران المستقل:**
   - شاشة مستقلة تدعم: ذهاب وعودة، ذهاب فقط، ومدن متعددة مع مقاطع ديناميكية.
   - عدادات منفصلة للبالغين، الأطفال، والرضع، واختيار أوزان الأمتعة ودرجة الطيران.
5. **خدمة التأشيرات:**
   - شبكة بطاقات بتدرجات لونية مميزة لكل دولة مع مدة الإنجاز والأسعار بالدولار وقوائم المستندات المطلوبة.

## 🖥️ لوحة تحكم الإدارة (Admin Web Dashboard)
- إحصائيات سريعة فورية للحجوزات والطلبات الجديدة والعملاء.
- جداول متخصصة لكل نوع من الطلبات مع إمكانية تحديث الحالة (`pending`, `confirmed`, `completed`, `cancelled`).
- تحكم كامل بكتالوج التأشيرات وإعدادات ومحددات مصمم الرحلة.
- نظام صلاحيات مزدوج: **مدير عام (Super Admin)** و **موظف مبيعات (Staff)**.

## 🗄️ توثيق هيكل بيانات ومستودعات Firestore (Data Architecture Guide)
تم إعداد نموذج توثيق فني شامل ومفصل يشرح بالتفصيل كيفية عمل الـ Repositories في Clean Architecture وهيكل البيانات لكل مجموعة:
- 📖 [اضغط هنا للاطلاع على الدليل الكامل: docs/FIRESTORE_DATA_ARCHITECTURE.md](docs/FIRESTORE_DATA_ARCHITECTURE.md)
  - هيكل مجموعة `bookings` (حجوزات الباقات وحقولها وأنواعها وأمثلة JSON).
  - هيكل مجموعة `custom_trip_requests` (محددات معالج الـ 6 خطوات وتوزيع الليالي).
  - هيكل مجموعة `visa_requests` (طلبات التأشيرات والأسعار وقوائم المستندات).
  - نماذج استدعاء كود المستودعات في Flutter عبر Riverpod.

## 🛡️ قواعد أمان Firestore (Security Rules)
- عزل كامل لبيانات العملاء؛ لا يمكن لأي مستخدم الوصول لحجوزات غيره.
- حظر تصعيد الرتب (`role escalation prevention`).
- الحذف النهائي والتعديل على الباقات محصور بالإدارة العليا.

## 🚀 تعليمات التشغيل والبناء (Build & Run Instructions)

### 1. إعداد الحزم المشتركة عبر Melos:
```bash
# تفعيل أداة melos عالمياً
dart pub global activate melos

# تثبيت وربط الحزم
melos bootstrap
```

### 2. تشغيل تطبيق العميل (Flutter Customer App):
```bash
cd packages/customer_app
flutter pub get
flutter run -d chrome # أو على محاكي Android / iOS
```

### 3. بناء تطبيق الأندرويد (APK / App Bundle):
```bash
cd packages/customer_app
flutter build apk --release
flutter build appbundle --release
```

### 4. تشغيل وبناء لوحة تحكم الإدارة (Flutter Web Admin):
```bash
cd packages/admin_dashboard
flutter pub get
flutter run -d chrome
flutter build web --release
```
